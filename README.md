# 🌤️ SkyCast — Aplicação de Previsão do Tempo

O **SkyCast** é uma aplicação web moderna para consulta de previsão do tempo em diferentes cidades. Desenvolvido com **HTML5, CSS3 e JavaScript**, o projeto oferece uma interface intuitiva, responsiva e agradável, proporcionando uma experiência fluida tanto em dispositivos móveis quanto em computadores.

---

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)
* API de previsão do tempo
* Google Fonts

---

## ✨ Funcionalidades

* 🔍 Pesquisa de cidades
* 🌎 Consulta de condições climáticas em tempo real
* 🌡️ Exibição da temperatura atual
* 💧 Informações de umidade do ar
* 🌬️ Velocidade do vento
* ☁️ Condições climáticas detalhadas
* 📱 Interface totalmente responsiva
* ⚡ Atualização rápida dos dados
* 🎨 Design moderno e intuitivo
